# Recoverable cognition implementation plan

> **For agentic workers:** Use executing-plans and test-driven-development for each task. Independent schema and pure context work may use dispatching-parallel-agents.

**Goal:** A bounded durable wake-to-decision state machine with deterministic recovery.
**Architecture:** Explicit SQLAlchemy/PostgreSQL stages retain exact context and decisions. Inference occurs outside transactions while a dedicated advisory session retains ownership.
**Tech Stack:** Existing synchronous Python, Pydantic, SQLAlchemy, Psycopg, Alembic, pytest.
**Spec:** `docs/superpowers/specs/2026-09-22-phase2-design.md`

## Global constraints

- Existing public protocol v1 schemas remain unchanged.
- No provider network calls inside SQL transactions; no new runtime dependencies.
- No secrets in canonical context, result errors, or configuration history.
- Genesis and governance cannot be changed through model semantic operations.
- User authorized routine choices and uninterrupted implementation; maintain reviewable commits.

## Review focus

Ownership loss in flight must fence writes; pause in flight must retain but defer a
decision; committed D1 must survive retries without sampling D2; frozen context
must survive config changes; invalid semantic operations must produce zero partial
effects. Each is covered in the runtime/recovery tasks below.
